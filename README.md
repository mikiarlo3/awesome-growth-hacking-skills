## Contributing

We welcome contributions! Please ensure any submitted skills follow the [Agent Skills standard](https://agentskills.io/) and provide genuine value for growth hacking, marketing, or revenue operations.

1. Fork the repository
2. Add the link to the appropriate category
3. Ensure the description is concise and accurate
4. Submit a Pull Request

*Note: This directory links to external, open-source resources. We do not accept links to proprietary paid tools or skills that encourage spam, terms-of-service evasion, or undisclosed automation.*
